2023·Distributed systems

ROS-Kafka gateway

Middleware that makes robot communication in ROS more reliable and fault-tolerant. Putting Kafka in the middle means you can reach the robot remotely, from a Kafka client or a ROS subscriber, on any machine. Built with Docker and Confluent Cloud, and published at IEEE CCEM.

GitHub ↗ Read the paper ↗
2023·Systems · C++

ghOSt vs. the Linux scheduler

I picked a widely used cloud workload that could benefit from user-space scheduling, rebuilt it as a micro-threaded app, and wrote a custom scheduler on Google's ghOSt to run it faster than Linux does. Then I wrote a practical guide to building ghOSt from scratch.
